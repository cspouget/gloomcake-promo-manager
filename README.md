# GloomCake HQ — Release Agent

Autonomous release/promo pipeline for GloomCake.

## Production flow

1. Upload master audio + optional lyrics at `/agent`.
2. Audio is uploaded directly to Vercel Blob.
3. A durable Vercel Workflow analyzes the master in Vercel Sandbox and selects three promo windows.
4. The creative director evaluates the song under the canonical GloomCake visual rules, develops exactly three radically different concepts, rejects the predictable one, and generates art-only artwork.
5. **Artwork approval gate.** Reject/regenerate or upload replacement art.
6. After approval, the exact approved GloomCake logo + title + `GC-###` catalog number are composited with Sharp. The logo is never generated by an image model.
7. FFmpeg renders three 1080×1920 H.264/AAC promo clips with the actual song audio.
8. TikTok, Instagram, YouTube Shorts, and SoundCloud copy is prepared.
9. **Campaign approval gate.**
10. Approved TikTok + YouTube clips are scheduled through Metricool using live best-time data.
11. Metricool analytics sync daily and become weak evidence for future creative/promo decisions without allowing repeated art concepts.

The original browser visualizer remains at `/`; the autonomous release system lives at `/agent`.

## Required production setup

Open `/agent/setup` after deployment. The readiness panel checks every requirement.

- `AGENT_ACCESS_KEY` — private password protecting the agent and release APIs.
- `OPENAI_API_KEY` — creative direction + artwork generation.
- Connected **Vercel Blob** store — injects `BLOB_READ_WRITE_TOKEN`.
- Exact official GloomCake logo — upload once through `/agent/setup`.
- `METRICOOL_API_TOKEN` — standalone scheduling + analytics. Metricool API access depends on the account plan.
- Deploy on Vercel so Sandbox + Workflow runtime authentication is available automatically.

Optional overrides:

- `METRICOOL_USER_ID` — defaults to `5303244`.
- `METRICOOL_BLOG_ID` — defaults to `6885961` (GloomCake).
- `METRICOOL_TIMEZONE` — defaults to `America/New_York` to match the Metricool brand.
- `GLOOMCAKE_LOGO_URL` — optional fallback instead of uploading the logo through setup.
- `CRON_SECRET` — recommended protection for the analytics cron endpoint.

## Routes

- `/agent` — release dashboard.
- `/agent/login` — private access-key login.
- `/agent/setup` — system readiness + exact logo configuration + manual analytics sync.
- `POST /api/releases` — create a release and start autonomous processing.
- `GET /api/releases` — list release jobs.
- `GET /api/releases/:id` — release state.
- `POST /api/releases/:id/approve-artwork` — approve art and start branding/rendering.
- `POST /api/releases/:id/regenerate-artwork` — reject art and generate a substantially different version.
- `POST /api/releases/:id/approve-campaign` — final publishing approval and scheduling.
- `GET /api/analytics/sync` — Metricool performance sync (also runs daily by Vercel Cron).
- `GET /api/agent/readiness` — configuration diagnostics.

## Safety / brand invariants

- Generated artwork contains **no** GloomCake logo, title, catalog number, or fake typography.
- Exact logo is composited only after explicit artwork approval.
- Visual consistency comes from taste, lighting, texture, strangeness, restraint, and editorial quality—not repeated portals, masks, mirrors, eclipse rings, portraits, or cyan cyberpunk.
- Publishing never happens before the final campaign approval gate.

## Stack

Next.js 16.3, React 19, Vercel Blob, Vercel Workflows, Vercel Sandbox, FFmpeg, Sharp, OpenAI Responses/Image APIs, and Metricool REST API.
